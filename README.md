One funny line of wedding vows for a robot couple — at most 160 characters,
written to be read aloud by a deadpan wedding officiant who laughs at exactly
one joke a year.

Run `main.ts` (Node 24 / TypeScript) and it writes the single-line vow to
`/output/entry.txt`, after validating the 1–160 character, single-line gate.
